# Security Policy

Do not open a public issue for a suspected credential leak or exploitable vulnerability. Contact the maintainers through the official HeFu support channel at https://hefu.hk/?support=1 and provide a sanitized description.

Never include API keys, OAuth tokens, client secrets, private prompts, model output, customer data or production request logs in an issue. The diagnostic JSON report is designed to exclude these values; verify it before sharing.

Supported version: the latest release on the default branch.
