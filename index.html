Common questions

What does API Doctor verify?

It checks that a selected model and protocol return a valid, non-empty response structure for one non-streaming request. It does not benchmark model quality, prove streaming support or validate your production workload.

Are prompts, outputs or API keys stored?

No. OAuth tokens and custom keys stay in page memory. Reports contain only allowlisted status, timing, public model ID and guidance fields—never prompts, outputs, credentials or endpoint URLs.

Is API Doctor free to use?

Yes. The open-source tool, preflight and configuration generator are free. A live check may incur provider charges and runs only after explicit confirmation, with one request and a 32-token output cap.

Which protocols and clients are supported?

HeFu OAuth supports OpenAI Chat Completions, OpenAI Responses and Anthropic Messages. Custom OpenAI-compatible endpoints support Chat Completions and Responses, including keyless localhost servers. Configuration examples cover Codex CLI, n8n, Claude Code, Cline, cURL, Python and Node.js.
